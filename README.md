# SPPB Vision – 5xSTS Assessment System

A Python-based computer vision and IMU system designed to automate
the Five Times Sit-to-Stand (5xSTS) assessment.

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas
- SciPy
- ESP32 / IMU sensors

## Features

- Real-time camera processing
- Human pose and movement analysis
- Lumbar IMU data acquisition
- Automatic detection of Sit-to-Stand repetitions
- Calculation of performance metrics
- Validation and testing utilities
